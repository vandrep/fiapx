## Agent skills

### Issue tracker

Issues e especificações são rastreados no GitHub Issues de `vandrep/fiapx`. Consulte `docs/agents/issue-tracker.md`.

### Triage labels

A triagem usa os cinco rótulos canônicos padrão. Consulte `docs/agents/triage-labels.md`.

### Domain docs

A documentação de domínio usa o layout single-context. Consulte `docs/agents/domain.md`.

### Arquitetura da aplicação

Ao iniciar ou alterar a aplicação-alvo, seu build, configuração, módulos, dependências, integrações ou testes, siga `docs/agents/architecture.md`.
