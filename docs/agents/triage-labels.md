# Rótulos de triagem

As skills usam cinco papéis canônicos de triagem. Esta tabela mapeia cada papel para o rótulo real no issue tracker.

| Rótulo em mattpocock/skills | Rótulo no tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa ser avaliada por um mantenedor |
| `needs-info` | `needs-info` | Aguarda mais informações do autor |
| `ready-for-agent` | `ready-for-agent` | Está especificada e pronta para um agente AFK |
| `ready-for-human` | `ready-for-human` | Exige implementação humana |
| `wontfix` | `wontfix` | Não será executada |

Quando uma skill mencionar um papel, use o rótulo correspondente desta tabela. Edite a coluna da direita se o tracker adotar outro vocabulário.
